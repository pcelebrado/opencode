# Jules Testing Workspace

This directory is the active test harness for validating Jules prompts,
execution quality, and review loops.

## Contents

- `test-repos/` - self-contained sample repositories for Jules tasks
- `JOURNAL_2026-03-02_PHASE3_TESTING_KICKOFF.md` - kickoff and process
- `JOURNAL_TEMPLATE.md` - template for all future test runs

## Policy

- New testing journals go here (not `docs/deployment`).
- Keep each test run reproducible with prompt, repo, expected output, and
  verification notes.
